# CAPRI Core v1

Пакет заменяет все основные файлы PWA CAPRI.

## Файлы
- `index.html` — интерфейс приложения.
- `style.css` — оформление для компьютера и iPhone.
- `app.js` — личность CAPRI, OpenRouter, история, локальная память и голосовые функции браузера.
- `manifest.json` — настройки установки PWA.
- `sw.js` — service worker и обновление кэша.
- `icon.svg` — иконка.

## Установка в существующий GitHub-репозиторий
1. Распакуй ZIP.
2. В репозитории `Versus1104/capri` открой корень репозитория.
3. Замени файлы одноимёнными файлами из архива. `README_RU_RO.md` можно добавить как новый файл.
4. Сделай Commit changes.
5. Подожди, пока GitHub Pages обновится, затем полностью закрой и заново открой CAPRI. При необходимости открой сайт в приватной вкладке для проверки.

## Важно
- История и воспоминания хранятся в `localStorage` конкретного браузера/устройства.
- Команды памяти: `Запомни: ...`, `Что ты помнишь обо мне?`, `Забудь: ...`, `Очисти память`.
- API-ключ вводится в настройках приложения и сохраняется локально. Не публикуй его. Для публичного приложения нужен серверный backend, который защищает ключ.
- Голосовое распознавание через браузер зависит от браузера и платформы. В iPhone Safari может потребоваться диктовка iOS-клавиатуры.
- PWA не может гарантировать постоянное прослушивание микрофона или работу голосового ИИ в фоне при заблокированном iPhone.
- История в этой версии сохраняется локально и включается в контекст ИИ. Автоматическое выделение новых воспоминаний из разговора — следующий этап.
